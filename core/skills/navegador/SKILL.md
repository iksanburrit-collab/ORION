# Navegador

## Cuándo utilizar
- cuando el usuario pide buscar información en la web
- cuando el usuario pide abrir una búsqueda en un buscador
- cuando el usuario pide abrir YouTube o una búsqueda en YouTube

## Herramientas relacionadas
- abrir_busqueda_web
- navegador_inteligente

## Reglas
- solo se abre el navegador predeterminado del sistema
- solo se construyen búsquedas con URLs fijas y consulta codificada
- no se navega a páginas arbitrarias ni se automatizan pestañas

# Sistema

## Cuándo utilizar
- cuando el usuario pide ayuda o los comandos disponibles
- cuando el usuario consulta el perfil guardado
- cuando el usuario consulta el estado de ORION
- cuando el usuario configura el modo de respuesta

## Herramientas relacionadas
- mostrar_ayuda
- mostrar_perfil
- mostrar_estado
- cambiar_modo

## Reglas
- nunca ejecutar comandos arbitrarios del usuario
- las acciones de control del PC requieren estar activadas en la configuración
- las acciones de riesgo alto están desactivadas por defecto
- las acciones de riesgo medio requieren confirmación
